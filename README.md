# ImageBrowser

一个使用 SwiftUI 开发的 macOS 图片浏览器应用，支持浏览、查看和管理图片文件。

## 系统要求

- macOS 12.0 或更高版本
- Xcode 13.0 或更高版本（用于开发）


### 安装

1. 克隆仓库
```bash
git clone [repository-url]
cd ImageBrowser
```

2. 构建项目
```bash
swift build
```

3. 运行应用
```bash
swift run
```


### 快捷键

- `回车` - 切换列表/单张视图
- `空格` - 单张视图播放/暂停自动播放
- `←/→` - 上一张/下一张图片
- `Delete/Backspace` - 删除当前图片
- `\` - 在 Finder 中显示当前图片
- `r` - 刷新图片列表
